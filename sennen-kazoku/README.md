# 천년가족 모바일 재구현 (비공식 팬 프로젝트 · 프로토타입 v0.1)

Unity 2D 세로형 스마트폰 게임으로 《천년가족》(GBA)을 재구현하는 프로젝트의 **첫 실행 버전 코드**입니다.
에뮬레이터 실행기가 아니며 원작 ROM·그래픽·음악을 포함하지 않습니다(그래픽은 전부 코드로 그린 임시 도형).

> **현재 상태를 정직하게**: 게임 로직(코어)은 `dotnet` 테스트 25개로 실제 검증했습니다. **Unity 에디터 실행, Android APK 빌드, 실제 기기 검증은 하지 못했습니다** — 이 환경에서 Unity 라이선스를 활성화할 수 없기 때문입니다. UI 코드는 UnityEngine 참조 어셈블리 대비 컴파일 오류만 없음을 확인했습니다. 자세한 내용은 [docs/04_검증결과.md](docs/04_검증결과.md).

## 실행 방법
### A. 지금 바로 가능한 것 (dotnet 8 SDK만 필요)
```bash
tools/run_checks.sh                       # 코어 테스트 31개 + 신규 팩 검사/미리보기
dotnet run --project tools/PackLintCli -- unity/Assets/Resources/BundledPacks 내팩.json --preview 이벤트id
```
### B. Unity에서 실행 (사용자 환경에서 필요)
1. Unity Hub로 **Unity 6000.3 LTS** 설치 (Android Build Support 모듈 포함) 후 `unity/` 폴더를 프로젝트로 열기. 첫 열기 때 패키지(uGUI, Input System)가 설치되고 `.meta` 파일이 생성됩니다(커밋 권장).
2. 메뉴 `천년가족 > 프로젝트 설정 적용 (세로 고정)` 실행(빈 씬 `Assets/Scenes/Main.unity` 생성 포함).
3. `Assets/Scenes/Main.unity`를 열고 ▶. 씬에 아무 것도 없어도 `Bootstrap`이 UI를 만듭니다. Game 뷰를 세로 해상도(1080×1920, 1080×2400 등)로 바꿔 확인.
4. Android: `Unity -batchmode -quit -projectPath unity -executeMethod SennenKazoku.EditorTools.BuildScript.BuildAndroid -output build/sennen.apk` (라이선스/SDK/NDK/JDK 필요). 패키지명 `com.example.sennenkazoku.proto`는 임시.
5. (선택) 원작 규칙 확장: 합법적으로 가진 공략 저장소 사본으로 로컬 팩 생성 →
   `python3 -I tools/import_original_pack.py <guide 저장소> unity/Assets/Resources/LocalPacks/sk.original.local.json`
   (**대사 포함, git 무시됨. 공개 금지.** 현재 예정 상태 918개 중 282개, 결과 이벤트 697개 변환.)

## 원작 그래픽 사용 (로컬 전용)
가지고 있는 ROM에서 직접 추출해 씁니다. 추출물은 git에서 제외되며 **배포하면 안 됩니다**.
```bash
sudo apt-get install libmgba-dev           # Ubuntu 기준
GUIDE_LAYOUT=<guide저장소>/assets/data/family-save-layout.json \
python3 -I tools/gba_capture/build_local_art.py <천년가족.gba>   # → unity/Assets/Resources/LocalArt/
```
추출 내용: 캐릭터 앞·뒷모습과 초상화, 큐피트, 하트·게이지 등 UI, 집 한 바퀴 배경, 원작 시작 가족(이름·생일·능력치·예정 상태). 자세한 내용은 [docs/07](docs/07_원작화면관찰.md)에 있습니다.

## 구현된 것
- 원작 구조 화면: HUD / 원작 집 단면도(가로 순환 스크롤) / 선택 인물 바 / 대화창 / 하단 메뉴(활쏘기·아이템·큐피트·관찰), 가족 터치 → 상세창, 세로 고정·안전영역·긴 화면 대응(계산부 테스트됨)
- 원작 시작 가족(로컬 추출 시), 실제 달력·요일, 화살(힘내라·진정해, 시작 각 5개)과 아이템(고리·행복 상자 등)
- 시간 진행(1일 틱, 관찰 메뉴에서 정지·×1/×2/×4, 따라가기), 이벤트 시작 시 자동 정지
- **원작 구조 이벤트**: 예정 상태 → 표 순서 첫 통과 결과 선택 → 효과 적용(샘플 3종: 규칙은 공략 데이터 값, 문구는 임시)
- **신규 이벤트 팩** `nova.pack001`(별도 파일·별도 packId, 선택지 포함)로 확장 구조 증명
- 선택지, 상태 변화(능력치/하트/직업 숙련도/무드/자산/플래그), 이벤트 기록
- 저장: 자동 저장 + 슬롯 3개, 이벤트 진행 중 저장·복원, `.bak` 복구, 스키마 마이그레이션 체인
- 가족 상세, 가계도(텍스트), 이벤트 기록, 콘텐츠 정보/업데이트 확인 화면
- 콘텐츠 팩 설치: 해시·검증·교차 검증 후 적용, 실패 시 롤백, 오프라인 사용, 진행 중 이벤트 보호
- 제작자 도구: `PackLintCli`(검사·분기별 미리보기·시뮬레이션), Unity 창 `천년가족 > 이벤트 팩 검사·미리보기`

## 아직 구현하지 않은 것
결혼·출산·사망·세대교체, 직업 이름/수입, 스킬 효과, 애정 붐 등 나머지 화살, 아이템 입수 경로, 시간대별 배경, 원작 걷기 경로, 원작 달력/이벤트 빈도, 컨디션·관계/상태 코드 기반 조건, 다중 후보 경로 상태(195개), 원작 그래픽·애니메이션·음악, 효과의 "몰입도·상태 보정", 팩 서명, 원격 서버, iOS, 정식 한글 폰트 번들, 단위 Unity PlayMode 테스트.

## 원작과 다른 점 (임시 구현 목록)
하루 1틱 진행 속도, 화살 효과 지속(7일), 하트 칸당 단위(96), 인물의 방 배정·이동, 예정 상태 배정·지연(20~60일), 이벤트 발생 빈도(하루 1/14), 연령 분류 경계, 하트 단위, 난수 알고리즘, 시작 가족, 모든 그래픽, 샘플 팩 대사. 화면에는 이벤트마다 `원작/신규 · 규칙 확인됨/추정/임시 · 원작 문구/임시 문구` 배지를 표시합니다.
