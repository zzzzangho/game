# 07. 원작 화면 관찰 (에뮬레이터 직접 실행)

`tools/gba_capture/capture.c`(libmgba, 헤드리스)로 사용자 ROM을 실행해 확인했다. 캡처 이미지와 상태 파일은 **로컬 전용**이며 저장소에 올리지 않는다.
빌드: `gcc -O2 -DUSE_DEBUGGERS -o capture capture.c -lmgba` (Ubuntu `libmgba-dev` 0.10. `-DUSE_DEBUGGERS` 없으면 구조체 배치가 달라 크래시).

## 확인한 화면 구조
- **메인 화면**: 집의 단면도가 가로로 이어지고(방 단위, 좌우 스크롤), 가족이 방 사이를 걸어 다닌다. 큐피트가 떠다니며 선택된 인물 위에 초록 화살표.
- **상단 HUD**: `N년가족`(가족 연차) · 날짜(요일 포함, 시작 날짜는 플레이어 입력) · 시계 아이콘 · R 버튼 표시.
- **하단 인물 바**: 얼굴, 이름, 하트 3칸(부분 채움 → 하트는 연속값), `★예정 상태 문구`, 세로 게이지, `활쏘기` 버튼.
- **인물 상세**(가족보기): 꿈, 맞은 화살, 지력·체력·매력·운 등급(F~SS), 하트, 신님에게 감사(개수), 나이, 세대주 왕관, `현재` 예정 상태 제목 + 설명 + 결과 경향(예: "무드↑↓변화 하트↑↓변화").
- **도입**: 천계의 신님 → "가족을 다음 세대로!" → 시작 연월일 입력 → 가족 소개 → 플레이어(신님) 이름 입력 → 큐피트 안내 → 화살 튜토리얼(힘내라/진정해의 화살 각 5개).
- 대화창: 둥근 말풍선형, 이름 파랑·키워드 초록/빨강 강조.

## 에셋 추출 가능성 (확인됨)
mGBA 레이어 토글로 분리 가능: OBJ(캐릭터·큐피트·말풍선 아이콘)만 / BG3(방 벽) / BG2(가구) / BG1(HUD 문자) / BG0(대화창).
→ 런타임 캡처 방식으로 원작 그래픽을 추출할 수 있다. 정적 ROM 압축 포맷을 몰라도 된다. 애니메이션은 연속 프레임으로 얻는다.

## 기존 프로토타입과의 차이 (반성)
첫 버전 UI는 원작 화면을 보지 않고 만든 일반적인 구성이었다. 원작의 핵심 시각 요소(집 단면도, 큐피트, 인물 바, 화살 조작)가 빠져 있었다. 다음 버전에서 원작 구조를 따라 다시 짠다.
