# 03. 작업 계획

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 자료·환경 조사, 설계, 계획 문서 | 완료 |
| 1 | **첫 실행 버전(이번)**: 가족 표시 → 시간 진행 → 예정 상태/원작 구조 이벤트 → 선택/상태 변화 → 저장·복원, 신규 이벤트 팩 별도 추가, 코어 테스트 | 코드·코어 테스트 완료 / **Unity 실행·APK·기기 미검증** |
| 1-a | Unity 에디터 설치·라이선스 활성화, 에디터 플레이 확인, UI 스크린샷 비율 검증 | **차단: 라이선스** |
| 1-b | `BuildScript.BuildAndroid`로 APK 빌드, 실기기 설치·세로 비율·안전영역 확인 | 1-a 이후 |
| 2 | 원작 시스템 확장: 관계/상태 코드 의미 해독(결혼·출산), 사망·세대교체, 직업 이름/수입 등급, 스킬 효과, 아이템·화살 UI | 미착수 |
| 3 | 원작 이벤트 커버리지 확대: 다중 후보 경로(195개 상태), 다른 인물 슬롯 조건, 컨디션 단계, `unknown` 판정 함수 해독, 제어 토큰 의미표 | 미착수 |
| 4 | 그래픽·음악: 포맷 리버스(자체 압축 추정), 권리 확인 후 대체 에셋 제작 또는 사용 결정 | 미착수 |
| 5 | 제작자 도구: 팩 검사 창(구현됨) → 이벤트 시각 편집기, 대사 토큰 미리보기, 시뮬레이션 통계 창 | 일부 |
| 6 | 콘텐츠 서버/CDN, 서명 검증(해시 외 서명), 신규 이벤트 팩 연재 | 미착수 |
| 7 | iOS 빌드(별도 단계), 스토어 출시 준비, 권리 문제 정리 | 미착수 |

원칙: 한 번에 전체를 완성했다고 주장하지 않는다. 각 단계마다 "확인/추정/미해명" 표와 검증 결과를 갱신한다.
