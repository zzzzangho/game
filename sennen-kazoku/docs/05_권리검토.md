# 05. 권리·라이선스 정리 (개발과 별도, 법률 자문 아님)

1. **원작 저작권**: 게임 본체·그래픽·음악·시나리오(일본어 원문과 한국어 번역 대사)의 권리는 원 권리자에게 있다. 팬 번역/패치 배포 이력과 무관하게 **상용 배포나 스토어 출시에는 권리자 허락이 필요**하다고 보는 것이 안전하다. 허락 없이는 스토어 게시·광고 수익화를 하지 말 것.
2. **이 저장소에 넣지 않은 것**: ROM, BPS, 세이브, 일본어 원문, 추출 그래픽/음악, **번역 대사 전체**. `import_original_pack.py`가 만드는 대사 포함 팩은 `Resources/LocalPacks/`(git 무시)에만 생성된다. 커밋되는 샘플 팩(`sk.sample`)의 제목·대사는 직접 쓴 임시 문구이고, 원작 규칙(조건·확률·효과 수치)과 원작 이벤트 id(`sourceRef`)만 참조한다.
3. **공략 사이트 데이터**: 저장소에 라이선스 파일이 없고 `COPYRIGHT.md`는 "법적 이용허락을 주장하지 않는다"고 명시한다. 즉 **데이터 재사용 권한이 불명확**하다. 상업적·공개 배포 전에 작성자(bwah-leaf)에게 이용 허락을 받아야 한다. 이 프로젝트는 데이터를 저장소에 복사하지 않고 로컬 변환만 한다.
4. **팬 번역가의 권리**: 번역문은 번역가의 2차적 저작물이다. 사용 전 동의 확인 필요.
5. **원작 규칙(게임 메커니즘)**: 아이디어/규칙 자체는 저작권 보호가 약하지만, 데이터 표 전체 복제는 위험하다. 공개 배포용 콘텐츠는 규칙을 이해한 뒤 **새로 쓴 이벤트(신규 팩)** 로 채우는 방향을 권장한다.
6. **서드파티**: 한글 폰트는 OFL 등 상용 사용이 가능한 라이선스(예: Noto Sans KR)를 번들해야 한다. 현재 OS 폰트 의존은 임시.
7. **상표/명칭**: "천년가족" 명칭·로고 사용도 권리 확인 대상. 출시용 이름은 별도 결정 필요.
8. 권리자가 요청하면 즉시 내리는 절차를 갖추고(연락처·삭제 프로세스), 비공개 테스트 배포(Internal testing)로 범위를 제한할 것.
